# ⚽ Online Sports Turf Booking System

A web-based **Online Sports Turf Booking System** built using Python, Flask, MySQL, HTML, CSS, and JavaScript. The application helps customers book sports turfs online while allowing turf owners and administrators to manage bookings and system activities.

---

## 📌 Overview

The Online Sports Turf Booking System provides a centralized platform for sports turf booking and management. It supports different user roles, helping customers access booking services while turf owners manage their facilities and administrators oversee the system.

The project aims to simplify the turf booking process and reduce the need for manual booking management.

---

## ✨ Features

- 🔐 Role-based access for Admin, Customer, and Turf Owner
- 👤 User account and access management
- ⚽ Sports turf discovery
- 📅 Turf booking management
- 🏟️ Turf owner management functionality
- 🛠️ Administrative management features
- 🗄️ MySQL database integration
- 🌐 Web-based user interface
